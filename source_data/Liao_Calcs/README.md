# FEFF database — shared folder

Updated **2026-08-19**. Everything below is FEFF 8L output generated by the
standardized direct-neighbour pipeline in `sl2977/FEFF_Database`
(`Python_codes/FEFF_calculations/`). The `.dat` files are gitignored, so this
folder — not GitHub — is how the data actually moves between people.

## Layout

    <Pair>/FEFF_paths(output)_<Pair>/<bin>/<run>/   feff.inp + feff000N.dat + the rest of the FEFF 8L output
    <Pair>/cif_files/<bin>/<run>.cif               the structure each run was built from
    <Pair>/feff_bins_summary_AMCSD.csv             per-structure selection + provenance
    feffdb_store/feffdb.db                         all of it as one SQLite file (see its README)

## What is here

32 bond pairs, 147 structures, 4395 `.dat` files:

    Co-C  Co-F  Co-N  Co-O  Cu-Cu Cu-F  Cu-N  Cu-O
    Fe-C  Fe-F  Fe-N  Fe-O  Mn-C  Mn-F  Mn-N  Mn-O
    Ni-C  Ni-Co Ni-F  Ni-N  Ni-O  Pt-Pt Ti-C  Ti-F
    Ti-N  Ti-O  Zn-C  Zn-Cl Zn-F  Zn-N  Zn-O  Zn-Se

Before this update the folder held only Cu-N, Cu-O, Cu-S and Zn-O; everything
added since July lived on the beamline host alone.

## Not current

- `_archive_2026-07-31_amcsd_sweep/` — the pre-2026-07-31 AMCSD sweep, kept as history.
  Holds Cu-N, Cu-S and eleven transition-metal oxides as they were before the
  direct-neighbour filter came in. Cu-S was retired at that point and removed from
  the top level on 2026-08-19; the archive copy is the one that remains. Co-O, Fe-O,
  Mn-O, Ni-O, Ti-O and Zn-O were recalculated and are current above; Cr-O, Mo-O,
  V-O, W-O and Zr-O exist only in the archive.
- `Co-Ni/` — absent. Its one structure has a bad deck; see `KNOWN_ISSUES.md`.
- `KNOWN_ISSUES.md` — the five decks held back from this folder and why.
